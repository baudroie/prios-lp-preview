# Prios LP preview

Client design preview hosted on GitHub Pages.

The phone consultation form records name, age, gender, and telephone in the owner's restricted Google Sheet through a public write-only Apps Script API. The form shows completion only after a matching confirmed receipt. Repeated requests with the same receipt ID do not create duplicate rows.

The connection was verified with clearly labeled synthetic data. Source and server code remain in the private repository.

LINE and job-card destinations remain demonstrations.
